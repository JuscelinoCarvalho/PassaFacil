# Roadmap

## Agora — Fundação do MVP

- [x] monorepo, API, interface e banco;
- [x] autenticação JWT e assinatura preparada;
- [x] modelos centrais e dados iniciais TCE-SP;
- [x] dashboard inicial e testes de autenticação;
- [ ] migrações Alembic e pipeline de integração contínua.

## Sprint 1 — Estudar de verdade

- [ ] onboarding com autoavaliação por disciplina;
- [x] plano diário persistido;
- [x] tela de questões, resposta e explicação;
- [x] caderno de erros;
- [x] primeira versão das revisões espaçadas;
- [x] painel alimentado pela API.

## Sprint 2 — Simulados e discursiva

- [x] simulado diagnóstico persistente com cronômetro;
- [ ] simulados configuráveis de 80 questões;
- [ ] análise por disciplina e tempo;
- [ ] estudos de caso semanais;
- [ ] rubrica de correção e histórico.

## Sprint 3 — Conteúdo e áudio

- [ ] importador de edital com revisão humana;
- [x] importador JSON de questões com proveniência e deduplicação;
- [x] upload privado e extração assistida de provas e gabaritos em PDF;
- [ ] associação automática entre questões e gabaritos definitivos;
- [ ] tela de revisão, classificação e aprovação de cada questão extraída;
- [ ] revisão editorial e licenciamento das coleções históricas;
- [ ] roteiros curtos e playlists de áudio;
- [ ] flashcards adaptativos;
- [ ] painel editorial e trilha de auditoria.
